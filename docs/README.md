# Hypoloom documentation

Current user entry points:

- [README](../README.md): capabilities and the shortest start path.
- [SETUP](../SETUP.md): installation, authentication and resource configuration.
- [USAGE](../USAGE.md): monitoring, human answers, cancellation and recovery.
- [Profile templates](../profiles/README.md): complete English/Chinese v4 examples.
- [Operator guide](operator-guide.md): English operational reference.
- [Architecture](architecture.md): components, ownership and durable boundaries.
- [Notifications](guides/notifications.md): explicit external delivery.
- [Qualification](qualification.md): G0–G5, runnable test selections and status.
- [Contributing](../CONTRIBUTING.md): local development and validation.

The root tutorials are the main user entry points. Qualification results belong
in the qualification document, rather than duplicated status tables throughout
the guides. Code, typed schemas and observable test outcomes resolve conflicts
in explanatory prose. Historical development transcripts are not shipped.

Codex development context is separate from the Claude Code runtime:
[AGENTS](../AGENTS.md), [CURRENT](codex-memory/CURRENT.md),
[INDEX](codex-memory/INDEX.md); runtime instructions are in [CLAUDE](../CLAUDE.md).
