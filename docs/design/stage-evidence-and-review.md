# Stage evidence and Verifier submission

A screening experiment can record a positive canonical local outcome while a later
experiment repeats that same measurement and puts contradictory new replications
only in its analysis. The Host correctly interprets the old parser, but a reader
cannot tell which observation the new success describes. Normal operation also
shows Verifier attempts spending their correction or output budget on the response
envelope. Neither problem depends on the research topic or inference provider.

Use the existing local measurement declaration, parser publication and independent
Oracle replay. An optional evidence plan names the stage, the exact units that
decide it, and an equal-weight mean or worst-unit rule. A unit can be a split,
dataset, repetition, condition or their intersection. A frozen parser emits one
value and optional paired baseline per unit. The Host transforms each pair before
reduction and applies the existing threshold once. Missing evidence is an invalid
measurement. A completed negative confirmation has its own scientific outcome.
Moving from screening to a new predicate uses the existing child/revision lineage.
The shared goal evaluator continues to own formal acceptance.

Existing Git captures, transactions and atomic files already preserve provenance.
They cannot express which units decide the predicate or infer whether a later
observation was independent. Use predeclared unit identities and existing frozen
source review for that purpose. Do not infer statistical independence from labels.
A configuration study can declare ranges at proposal, screen cheaply on validation,
and reserve its wider budget for promising candidates and fresh confirmation units.
Cross-run handoff uses ordinary declared task inputs with source references.

For fresh Verifier attempts, project the model-owned report fields from the
existing admitted schema. The Host supplies the task discriminator and required
effect, then runs the existing full-schema and semantic validators. Tool preparation
and Stop share their current session, correction budget and atomic output. There
is no separate report or checkpoint. Old scalar measurements, full final responses
and ACI 39 tool submissions keep their original interpretation.

Maintenance comprises two versioned input shapes, independent arithmetic and
regressions at parser, submission and real CPU workflow boundaries. The compact
projection can be retired if native structured completion supplies the same bound
fields. The evidence shape could be retired for new runs if a future measurement
contract represents unit-level decisions directly. Historical runs retain their
original declarations and pinned runtime.
