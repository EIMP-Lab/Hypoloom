# Engineering requirements and known-answer measurements

An independently approved screening job used its own training loop and returned
validation scores without a reloadable checkpoint. The project had already named
both requirements in its scientific goal. The independent reviewer receives only
engineering inputs. Protecting the reference implementation in Git prevents edits
but cannot establish which implementation ran.

Profile authors can name a small set of engineering assertions in the goal.
The verifier receives their IDs and descriptions from the admitted Profile.
Each needs observed coverage under the existing inspect, probe and review
protocol. Authors specify requirements that apply to their project, including
observable behavior when reusing an earlier artifact.

Five completed jobs produced rejected local measurement records. A different
parser emitted a signed change as the candidate's absolute value, which caused
the Host to subtract the reference twice. Git captures those errors faithfully.
The existing design smoke checked a sample's structure but had no independently
specified numeric answer, and the execution author can change the parser before
its first submission. New local measurement cases reuse the existing CPU parser
sandbox and adjudicator. Examples live with the author's test inputs. Admission
checks the actual submitted bytes before the Host freezes them.
The native endpoint runs the bounded parser work off the writer thread. The
writer then rechecks the attempt, current admission controls and replay key
against the original capture before it creates an experiment.

Two consecutive revisions of a verifier fixture produced the same unchanged
perturbation while the submitted entrypoint also failed. Changing verifier code
cannot repair a submitted command. The review uses observed check IDs, statuses
and details from the same delivery to assign the next action. A repeated fixture
error can leave verification inconclusive. A candidate defect requires separate
evidence. Neither outcome determines a scientific score.

These changes use the existing Profile projection, captured submission, probe
records and review coverage. They introduce no database table or secondary
result authority. The maintenance surface is an optional Profile field, the
local fixture reader and versioned validation at existing boundaries. Retire
these checks if a successor contract supplies equivalent observed evidence.
