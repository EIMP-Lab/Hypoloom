# Literature and hypotheses

Use the supplied sources, previous accepted findings and open questions first.
Read original methods or results where a claim depends on details; an index or
search abstract alone is not full-paper evidence. Resolve relevant gaps rather
than repeating discovery already supported by accessible, current material.

Use the existing literature skill and bounded reader tools for selected sources.
Document tools try public/OA copies and existing institutional sessions. Pending
work has a deadline; continue other papers instead of repeatedly polling or waiting
for login. Unavailable, skipped, denied or timed-out sources remain explicit evidence
gaps. Use permitted academic search for alternatives, preserve the actual source
and version, and never substitute another paper under the missing paper's citation.
An OA copy does not establish that it is the publisher's final version.
Time strata supply historical candidates, not a scientific relevance ranking.
Choose papers for specific evidence questions. Use targeted academic follow-up
when broad discovery misses the task's methods or evaluation details; do not
broaden that targeted query merely to fill older year bins. A batch missing PDF
can still be selected through web_fetch(mode=document, url=...). Consult the
candidate URLs and observed access modes in /papers/INDEX.md. Acquisition route,
full-text availability, actual page reading and interpretation are separate;
older sources without route metadata remain unknown.
Separate source claims, your interpretation and uncertainty. Design hypotheses
that distinguish plausible explanations with feasible experiments; preserve the
accepted goal and declared local/GOAL measurement choices.

For hypothesis batches, use the admitted effective_max_forks and the actual
exploration_progress. Develop independent evidence-backed alternatives when
available, keeping one mechanism per chain. Each can have a small discriminating
experiment; one running chain need not prevent another chain's preparation.
Do not bundle dependent steps as independent hypotheses or fill slots with
hyperparameter variants. Explain unused width in existing claim/assumptions.

Choose the smallest informative LOCAL comparison permitted by the methodology
before freezing its measurement. Reserve costly full matrices for questions
that need them; formal GOAL evaluation still requires all accepted seeds, arms,
datasets and checks. Screening evidence never substitutes for those obligations.

This stage does not require an evaluator, code changes or test fixtures merely
to satisfy a shared workflow. Hand off precise assumptions, evidence references
and discriminating tests using the current node's supplied response schema.

When choosing a local measurement, state which uncertainty the screening result
will resolve and how it informs the next experiment. If the claim is improvement,
use an appropriate matched baseline or justify an absolute target. A raw positive
score can demonstrate feasibility without demonstrating an improvement. A zero
target is valid for many gains and errors; do not infer meaning from its sign or
metric name. Preserve goal constraints, dataset/split boundaries and aggregation:
an average must not conceal regressions where the goal requires separate targets.
Use existing VALUE/delta/relative-delta declarations when appropriate. No local
measurement (GOAL-only) remains valid. Change a frozen measurement through a new
or revised hypothesis, never by silently editing an accepted one.
