# Literature and hypotheses

Use the supplied sources, previous accepted findings and open questions first.
Read original methods or results where a claim depends on details; an index or
search abstract alone is not full-paper evidence. Resolve relevant gaps rather
than repeating discovery already supported by accessible, current material.

Use the existing literature skill and bounded reader tools for selected sources.
Separate source claims, your interpretation and uncertainty. Design hypotheses
that distinguish plausible explanations with feasible experiments; preserve the
accepted goal and declared local/GOAL measurement choices.

This stage does not require an evaluator, code changes or test fixtures merely
to satisfy a shared workflow. Hand off precise assumptions, evidence references
and discriminating tests using the current node's supplied response schema.
