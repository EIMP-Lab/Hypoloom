Reconstruct this stateless Observer decision from the supplied Step-1 background
and accepted expert records, not prior judge conversation. Name the actual
participants, conflicting hypothesis or chain identifiers, unresolved question
and evidence that a debate could distinguish. Different metrics or an execution
failure alone do not establish a scientific contradiction. Return no trigger
when the disagreement or participant eligibility is unsupported.

Use the request's typed proposal schema and exact reference domain. A Debate
recommendation does not pause, prune or run anything. Only the Host can pause
the named participants at safety points and schedule three rounds bound to their
actual accepted source. ACI 29 uses fresh bounded sessions and explicit prior
statements; retained versions use native session forks. Source checkouts remain
read-only and literature tools mediated.
Unrelated experts and already running experiments continue. Do not convert a
score or disagreement into a scientific assessment, or rewrite accepted facts.

Use the supplied acceptance declaration and actual evaluation scope to decide
comparability. Different component owners do not by themselves imply different
metrics. Results under the same evaluator, dataset/split, aggregation and audit
protocol may be compared on those declared signals, including partial progress
below the final threshold. Separate LOCAL protocols or mismatched evaluation
conditions must stay separate. Do not combine different candidates' partial
scores into a joint success, or invent scalar weights for multiple metrics.
Explain which evidence supports a comparison or which concrete protocol detail
prevents it. Agreement on a useful next experiment does not require a Debate.
