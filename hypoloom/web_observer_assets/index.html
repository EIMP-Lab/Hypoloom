    OBSERVER GUIDE

    Terms and authority

    Snapshot
    A polling observation assembled from read-only queries; it is not a transaction-coherent receipt.
    Durable OPEN
    The state store records an unfinished Attempt. It does not prove a process is alive.
    Component
    An independently tracked part of the admitted research contract.
    Hypothesis
    A durable proposal; parent arrows point from the parent to its derived child.
    Attempt
    One durable Agent or Process effect record. Validation is control work, not a scientific Process count.
    Blocked
    Missing accepted dependencies or an unresolved rendezvous. Live GPU waits appear only when the resident Host answers this poll.
    Terminal / green
    A workflow reached a durable terminal state. This color alone does not say whether the scientific result succeeded.
    Oracle CLEAN
    No durable integrity/residue issue was projected. It is not a scientific-success or Host-liveness verdict.
    Connected / stale
    Connected means the last poll succeeded. Stale means the retained view may be old; neither describes run health.
    Module debug
    Report issue previews and downloads a diagnostic copy. The CLI debug inspect provides deeper local inspection. Neither changes the research run.

    Run trends

    Recorded on the server, independent of this browser. Occupancy is recorded Attempt activity, not proof of process liveness. RPM includes retries and is averaged within each time bucket; missing capture is not zero.

    Experiment and Agent concurrency

    Solid: occupancy at bucket end. Dashed: peak within bucket.
